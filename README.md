Meus projetos (plugins Decky Loader para Steam Deck e outros). Uma pasta por projeto.

| Pasta | Descrição |
|---|---|
| `save-backup-sd/` | Backup e restauração de saves para o microSD, com backup automático ao fechar o jogo |
| `ps5-dashboard/` | Tela inicial do Modo Jogo no estilo PlayStation 5 (versão modificada, com opção de remover o footer) |
